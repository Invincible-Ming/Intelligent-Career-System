AI 智能体创新实习生（Agent Building 方向）

岗位描述与任职要求 · 来源：BOSS 直聘

一、我们能给你什么

  • 拒绝"搬砖"：你不会被用来做重复性杂活。你的核心任务是消灭重复性劳动。
  • 真实战场：直接接触公司核心业务逻辑（供应链 / 内容流 / 管理流），你的每一个 Agent 都会产生真实的商业价值。
  • 高维视野：由技术大牛带队，探索 Agentic Workflow（智能体工作流）在企业级场景的极限边界。
  • 转正机会：表现优异者后期可直接转正式员工。

二、你需要做什么

  • 场景极客：对接业务部门需求，但不止步于需求。深度理解业务逻辑，敏锐捕捉可以用 AI 重构的"低效环节"。
  • 智能体架构（Agent Building）：利用 Coze / Dify / LangChain / CrewAI 等工具或框架，从 0 到 1 搭建智能体。不仅仅是写 Prompt，更要设计工作流（Workflow）、配置知识库（RAG）、调用外部 API 与工具链。
  • 方案落地与迭代（Solution & Iteration）：针对我们将提供的具体业务难题（如自动化营销、数据分析、流程自动化等），设计创新解决方案。从 Demo 到 MVP，不断调试模型表现，让 Agent 越来越聪明。

三、我们要找这样的你

  • 学历背景：2027 年毕业的在读硕士研究生，计算机、软件工程、数学或跨学科背景。
  • 核心能力 — AI Native 思维：习惯用 AI 解决问题。熟练掌握 Prompt Engineering，对 GPT-5、Claude 4、DeepSeek V3/R1、Gemini 2.5 等主流模型特性如数家珍。
  • 工具掌控力：必须熟悉至少一种智能体编排平台（如 Coze、Dify、FastGPT 等），有实际搭建过复杂工作流（Workflow）的经验。了解 MCP（Model Context Protocol）协议者优先。
  • 编程基础：具备 Python 基础，能看懂 API 文档，能写简单的 Glue Code（胶水代码）来连接不同工具者优先。

四、加分项（只要中一条，请务必告诉我们）

  • 你是"提示词工程师（Prompt Engineer）"，在 GitHub 或社区分享过高质量 Prompt。
  • 你有自己运营的 AI 账号、Bot 或开发过独立小产品。
  • 你对自动化脚本或多模态生成（Flux / Midjourney V7 / Sora 等）有涉猎（因为我们的技术栈很广阔）。
  • 你有过 Multi-Agent（多智能体协作）项目的实际落地经验。
